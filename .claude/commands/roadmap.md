View or add to `docs/ROADMAP.md`, depending on the argument given.

**No argument / "show":** print the current epics and their not-done items only
(skip anything marked **[DONE]**), grouped by epic, with priority and Owner.

**Adding an item:** append it to the most fitting existing epic (or propose a new one
if it genuinely doesn't fit) using the existing format — bolded `**ID. Title.** —
Priority, Size` followed by a short paragraph of what and why. Assign Owner (blank =
Claude, **me** = needs the user) and add it to the "Suggested sequencing" /
"waiting on you" section if relevant.

Don't reorder or rewrite existing items while doing this — append only.
