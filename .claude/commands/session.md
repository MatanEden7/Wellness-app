Write today's entry in `docs/SESSION.md`, prepended above the most recent existing
entry (most-recent-first order).

Format, matching existing entries:

```
## YYYY-MM-DD

**Current task:** ...

**Last completed:**
- bulleted summary of what shipped this session

**Next task:** ...
```

Keep "Last completed" to what actually happened this session, not a restatement of
old work. If this is a mid-session checkpoint rather than the end of a session, still
use today's date — a second same-day entry replaces the first same-day entry rather
than duplicating it.
